I build open-source software for simulation, data analysis, research workflows, and reproducible programming. I am the main developer of **Agents.jl**, **EvoDynamics.jl**, and **ShamirSSS.jl**, and contribute to the wider Julia ecosystem.

## Scientific Packages

- [**Agents.jl**](https://github.com/JuliaDynamics/Agents.jl){:target="_blank"}: A performant, feature-rich Julia framework for agent-based modeling. Published in the *Journal of Open Source Software*.
- [**EvoDynamics.jl**](https://github.com/kavir1698/EvoDynamics.jl){:target="_blank"}: Simulation of eco-evolutionary dynamics on multi-trait networks.
- [**ShamirSSS.jl**](https://github.com/kavir1698/ShamirSSS.jl){:target="_blank"}: A Julia implementation of Shamir's Secret Sharing Scheme.
- [**FuzzyCognitiveMaps.jl**](https://github.com/kavir1698/FuzzyCognitiveMaps.jl){:target="_blank"}: A Julia package for creating and manipulating fuzzy cognitive maps.

## Tools and Experiments

- [**CodeNavigator.jl**](https://github.com/kavir1698/CodeNavigator.jl){:target="_blank"}: Visualizes Julia code bases.
- [**LifeCalendar**](https://github.com/kavir1698/LifeCalendar.jl){:target="_blank"}: Creates a life-calendar visualization in weeks.
- [**GraphNotes**](https://github.com/kavir1698/GraphNotes){:target="_blank"}: Converts research notes into a graph for easier retrieval.
- [**Moeen thesaurus**](https://github.com/kavir1698/Moeen_thesaurus){:target="_blank"}: Uses NLP techniques to analyze lexical patterns in the Moeen Dictionary.
- [**FoodRecom.jl**](https://github.com/kavir1698/FoodRecom){:target="_blank"}: A Julia package for food recommendation systems.
