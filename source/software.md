# Software

I have created a few packages and frameworks:

* [__EvoDynamics.jl__](https://github.com/kavir1698/EvoDynamics.jl){:target="_blank"}: Simulation of eco-evolutionary dynamics on multi-trait networks.
* [__Agents.jl__](https://github.com/JuliaDynamics/Agents.jl){:target="_blank"}: An agent-based modeling framework.
* [__ShamirSSS.jl__](https://github.com/kavir1698/ShamirSSS.jl){:target="_blank"}: A Julia implementation of Shamir's Secret Sharing Scheme.
* [__FuzzyCognitiveMaps.jl__](https://github.com/kavir1698/FuzzyCognitiveMaps.jl){:target="_blank"}: A Julia package for creating and manipulating fuzzy cognitive maps.
* [__CodeNavigator.jl__](https://github.com/kavir1698/CodeNavigator.jl){:target="_blank"}: A tool for visualizing Julia code bases.
* [__LifeCalendar.jl__](https://github.com/kavir1698/LifeCalendar.jl){:target="_blank"}: Create a life calendar visualization in weeks.
* [__GraphNotes__](https://github.com/kavir1698/GraphNotes){:target="_blank"}: A tool that converts your research notes to a graph so that finding relevant information in the future becomes easier.
* [__Moeen thesaurus__](https://github.com/kavir1698/Moeen_thesaurus){:target="_blank"}: a thesaurus of Persian nouns from Moeen Dictionary.
* [__FoodRecom.jl__](https://github.com/kavir1698/FoodRecom){:target="_blank"}: A Julia package for food recommendation systems.
