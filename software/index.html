Software

I have created a few packages and frameworks:

  • EvoDynamics.jl: Simulation of eco-evolutionary dynamics on multi-trait networks.
  • Agents.jl: An agent-based modeling framework.
  • ShamirSSS.jl: A Julia implementation of Shamir’s Secret Sharing Scheme.
  • FuzzyCognitiveMaps.jl: A Julia package for creating and manipulating fuzzy cognitive maps.
  • CodeNavigator.jl: A tool for visualizing Julia code bases.
  • LifeCalendar.jl: Create a life calendar visualization in weeks.
  • GraphNotes: A tool that converts your research notes to a graph so that finding relevant information in the future becomes easier.
  • Moeen thesaurus: a thesaurus of Persian nouns from Moeen Dictionary.
  • FoodRecom.jl: A Julia package for food recommendation systems.
