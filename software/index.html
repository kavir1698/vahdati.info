Software

I build open-source software for simulation, data analysis, research workflows, and reproducible programming. I am the main developer of Agents.jl, EvoDynamics.jl, and ShamirSSS.jl, and contribute to the wider Julia ecosystem.

Scientific Packages

  • Agents.jl: A performant, feature-rich Julia framework for agent-based modeling. Published in the Journal of Open Source Software.
  • EvoDynamics.jl: Simulation of eco-evolutionary dynamics on multi-trait networks.
  • ShamirSSS.jl: A Julia implementation of Shamir’s Secret Sharing Scheme.
  • FuzzyCognitiveMaps.jl: A Julia package for creating and manipulating fuzzy cognitive maps.

Tools and Experiments

  • Zurstuna: A local-first, cross-platform web application for creating and maintaining PlantUML Gantt diagrams through visual controls.
  • CodeNavigator.jl: Visualizes Julia code bases.
  • LifeCalendar: Creates a life-calendar visualization in weeks.
  • GraphNotes: Converts research notes into a graph for easier retrieval.
  • Moeen thesaurus: Uses NLP techniques to analyze lexical patterns in the Moeen Dictionary.
  • FoodRecom.jl: A Julia package for food recommendation systems.
